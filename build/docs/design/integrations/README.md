# Integrations

As you can see form the design below there are a few system which we integrate too.

![High level design](/build/docs/content/.attachments/processes/activation/High%20Level%20Resources.png "Some test")

At a high level we connect to:

* INFOR CloudSuite Data Lake
* INFOR CloudSuite Skeletal Assets (Calling our Api)
* IPG
* IPG RAA integrations via Service Bus
* MDP SQL Server
* FAM DB for CPQ Tables
